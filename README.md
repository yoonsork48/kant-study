#git tutorial

```bash
# 깃 초기화
git init

# 스테이징 추가
git add .
git add -A
```

```bash
# commit
git commit -m "commit message..."

git push origin main
```

```sh
# git 로그 명령어

git log
git log --oneline
git log --oneline --all

```
